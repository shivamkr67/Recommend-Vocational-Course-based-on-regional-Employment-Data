# Vocational & Tech Training Recommender

A Streamlit app that recommends vocational and technology training programs in India by matching target job skills with available program skills.

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```
